# LiveMedCard

**Жива медична картка** для літньої людини — прототип для Digital Future Hackathon
(ніша Aging & Longevity). Структурує медичні документи (українські й англомовні) у
**лонгітюдний таймлайн**, детерміновано помічає **небезпечні взаємодії ліків і тренди
показників**, відповідає на питання природною мовою з посиланням на джерело.

Демо стартує із заповненою білінгвальною карткою (UA-виписки + англомовний
lab-report). Архітектура — **TRACE** (вимірювана межа довіри): сигнали безпеки
рахуються детерміновано, а не генеративною моделлю. Система **не ставить діагнозів**.

> Цей публічний демо — детермінований `stub`-режим (без хмарних LLM). У продукті
> обробка локальна, на пристрої (privacy by design).

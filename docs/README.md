# docs/ — сайт GitHub Pages

Самодостатній статичний сайт проєкту LiveMedCard. Нічого не збирається, залежностей
немає, працює і локально (подвійний клік по `index.html`), і як GitHub Pages.

## Що всередині

- `index.html` — хаб: посилання на два застосунки + вбудований переглядач Markdown
  (аналіз, ADR, економіка, README — контент вшито в сторінку, читається офлайн).
- `observatory.html` — «Обсерваторія історії»: радіальний темпоральний граф знань
  з анімованим відтворенням.
- `showcase.html` — презентація для колег і керівництва.
- `.nojekyll` — вимикає обробку Jekyll (віддавати файли як є).

## Як опублікувати (робить власник репозиторію — це зовнішня дія)

1. Закомітити теку `docs/` у гілку `main` і запушити.
2. Repository → **Settings → Pages**.
3. **Source: Deploy from a branch**, гілка `main`, тека **`/docs`**, Save.
4. За ~1 хв сайт буде за адресою `https://<user>.github.io/<repo>/`.

Локальний прев'ю без пушу:

```bash
python3 -m http.server -d docs 8000   # → http://127.0.0.1:8000
```

Дані демо-картки (mom-001) вбудовані у візуалізації; жодних реальних PHI, жодного
серверного бекенда.
